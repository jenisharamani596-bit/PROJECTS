🚀 Python Projects Repository
Welcome to my collection of Python projects! This repository contains various beginner-to-intermediate Python scripts and mini-projects created to practice programming concepts, logic-building, and user-input handling.

📂 Project Structure
Here is an overview of the folders and files included in this repository:

calculatorsimple/: Contains simple calculator or interest/conversion Python programs.

conversion/: Programs built for various unit and value conversions.

information/: Interactive scripts that use the input() function to collect and display personal details (name, age, city, hobby, programming language).

oprator/: Projects demonstrating the use of various operators in Python.

portofliyo/: A professional portfolio UI created in Python.

calculator.py: A standalone basic calculator script.
